# Quick Deploy Options for fraction-game

## Option 1: Netlify Drop (Fastest - 30 seconds)
1. Go to https://app.netlify.com/drop
2. Drag the `fraction-game` folder onto the page
3. Done! You'll get a URL like `random-name.netlify.app`

## Option 2: GitHub Pages (Your repo)
1. Create new repo at https://github.com/new
2. Name it `fraction-game`
3. Upload index.html
4. Go to Settings → Pages → Deploy from main branch
5. URL: `https://rajkcho.github.io/fraction-game`

## Option 3: Vercel
1. Go to https://vercel.com/new
2. Import from your GitHub or upload directly
3. Done!
